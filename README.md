# 테트리스 2.0

Visual Studio(C++20)로 만든 콘솔 테트리스입니다.
기본 테트리스의 블록 배치와 줄 제거를 유지하면서, 특수 블록과 게임 모드를 추가했습니다.
터미널 렌더링에는 [Rsact](https://github.com/MovingJu/Rsact) 라이브러리(MIT 라이선스)를 사용했습니다.

## 기능

- 기본: 이동/회전/줄 제거/점수/레벨, 다음 블록, 고스트 블록, 홀드(블록당 1회), 되돌리기(한 판 3회)
- 게임 모드 (모드끼리는 옵션이 섞이지 않습니다)

| 모드 | 내용 |
|---|---|
| STANDARD | Classic, 무회전(블록이 랜덤 방향으로 생성), N종류 블록, 단단한 블록(두 번 깨야 사라짐) |
| BOMB | 게이지가 차면 폭탄 블록 등장, 폭탄 줄을 지우면 위·아래 줄도 제거, 돌 줄 난이도(EASY/NORMAL/HARD), 연쇄 폭발 옵션 |
| INVISIBLE | 놓은 블록이 몇 초 뒤 투명해지는 기억력 모드 (6초/3초/1.5초) |

## 조작키

| 키 | 동작 |
|---|---|
| ← → (A, D) | 이동 |
| ↑ (W) | 회전 |
| ↓ (S) | 소프트 드롭 |
| Space | 하드 드롭 |
| C | 홀드 |
| Z (U) | 되돌리기 |
| P / R / M / Q | 일시정지 / 재시작 / 메뉴 / 종료 |

메뉴에서는 방향키로 선택하고 값을 바꾼 뒤 Enter 또는 Space로 시작합니다.

## 빌드 방법 (Windows)

필요한 것: Visual Studio 2022 (C++를 사용한 데스크톱 개발, CMake 도구), Git, Rust 1.85 이상

1. 이 저장소를 clone 합니다.
2. Visual Studio에서 **파일 → 열기 → 폴더**로 저장소 폴더를 엽니다.
3. CMake 구성이 끝나면 (처음에는 Rust 라이브러리를 빌드해서 몇 분 걸립니다) 시작 항목을 `tetris.exe`로 선택합니다.
4. 빌드 후 **Windows Terminal**에서 실행하세요. (Visual Studio 기본 디버그 콘솔에서는 실행되지 않을 수 있습니다.)
   창 크기는 가로 50칸, 세로 28줄 이상이어야 합니다.

## 폴더 구조

| 파일 | 역할 |
|---|---|
| `src/main.cpp` | 메뉴/게임 화면 전환과 메인 루프 |
| `src/Screen.*` | Rsact 래퍼 |
| `src/Input.*` | 키 입력 스레드 |
| `src/Piece.*` | 블록 모양과 회전 |
| `src/Board.*` | 판, 충돌, 줄 제거(폭탄/단단한 블록/돌 줄) |
| `src/Game.*` | 게임 규칙, 점수, 홀드, 되돌리기, 화면 출력 |
| `src/Menu.*` | 모드 선택 화면 |
